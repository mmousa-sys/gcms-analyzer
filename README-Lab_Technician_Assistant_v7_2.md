# Lab Technician Assistant v7.2 (Python desktop edition)

This is the Python desktop program described in the supplied v7.2 PDF. It is
separate from the browser-based Lab Technician Assistant v9.2 HTML application.
The source listing was recovered from the PDF; the PDF did not include a
prebuilt Windows executable.

## Requirements

- Python 3.9 or newer
- Tkinter (included with most standard Python installers)
- CustomTkinter

## Install and run

1. Download and extract `Lab_Technician_Assistant_v7_2.zip`.
2. Open a terminal in the extracted folder.
3. Install the dependency:

   ```text
   python -m pip install -r requirements-lab-technician-assistant-v7.2.txt
   ```

4. Start the desktop app:

   ```text
   python Lab_Technician_Assistant_v7_2.py
   ```

After installation, the application works offline. The interface includes
Arabic, English, and German.
